# KIET University Website  A 5-page university website created as part of a university assignment using **HTML, CSS, and JavaScript**.  ### Features - Home Page - About KIET University - Departments Information - Academic Programs - Admission Inquiry Form - Campus Images and Video - Navigation Bar and Search Box - Responsive Layout for Laptop, Tablet, and Mobile Screens  ### Technologies Used - HTML5 - CSS3 - JavaScript  ### Project Purpose This project was developed to practice front-end web development skills, including webpage structure, styling, layouts, navigation, forms, and responsive web design.  **Designed by a KIET University Student.**
